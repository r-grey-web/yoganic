# Yoganic

![Yoganicのトップ画像](web/img/hero-img.webp)

## Overview
架空のオンラインヨガサービス「Yoganic」をテーマに制作したWebサイトです。

自身で制作したデザインカンプをもとにHTML、Sass、JavaScriptでコーディングを行い、
FLOCSS設計、BEM命名規則、Sassを用いて保守性・再利用性を意識して実装しました。
